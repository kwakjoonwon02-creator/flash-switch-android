# 모두의 갤러리 — Google Apps Script 익명 커뮤니티

디시인사이드처럼 **갤러리 · 말머리 · 개념글 · 추천/비추 · 댓글/답글 · 사진 첨부**가 되는 익명 커뮤니티입니다.
서버나 호스팅 없이 **Google Apps Script 웹 앱 하나**로 돌아갑니다.

- 화면·서버: Apps Script 웹 앱 (`HtmlService` + `google.script.run`)
- 데이터베이스: 자동으로 만들어지는 Google 스프레드시트
- 사진 저장: Google Drive 폴더

> 디시인사이드의 사용 방식을 참고한 독립 프로젝트이며 디시인사이드와는 관계가 없습니다.

## 주요 기능

| 구분 | 기능 |
| --- | --- |
| 갤러리 | 자유·사진·유머·건의 갤러리 기본 제공, 관리자 페이지에서 추가·이름 변경·숨기기 |
| 글 목록 | 번호 · 말머리 · 제목 `[댓글 수]` · 글쓴이(식별코드) · 작성일 · 조회 · 추천, **전체글 / 개념글 / 공지** 탭, 말머리 필터, 검색(제목+내용 / 제목 / 내용 / 글쓴이), 10쪽 단위 페이지 |
| 글쓰기 | 닉네임(비우면 `ㅇㅇ`) + 비밀번호, 말머리, **사진 최대 20장** (버튼 · 드래그 앤 드롭 · Ctrl+V 붙여넣기), 본문 `[사진1]` 자리에 사진 배치 |
| 사진 | 큰 사진은 브라우저에서 긴 변 1600px로 자동 축소 · 위치정보(EXIF) 제거, GIF는 원본 그대로(움짤), 클릭하면 크게 보기 |
| 글 보기 | 추천 / 비추천 (기기당 1번, 자기 글 불가), 추천 수가 기준을 넘으면 **개념글**, 주소 복사, 아래쪽에 갤러리 목록 |
| 댓글 | 댓글 · 답글(한 단계), 답글이 남아 있으면 "삭제된 댓글입니다" 자리 유지 |
| 수정·삭제 | 글/댓글 쓸 때 정한 비밀번호로 수정·삭제 |
| 첫 화면 | 갤러리 목록(오늘 올라온 글 수), **실시간 베스트**(최근 72시간 추천순, 썸네일), 최신 글, 개념글 |
| 관리자 | 스크립트 주인 계정은 자동 관리자, 관리자 키 로그인, 비밀번호 없이 글·댓글 삭제, 공지 올리기, **작성자 차단**(1일·7일·30일·영구), 갤러리 관리 |
| 보호 | 도배 방지(글 20초·댓글 5초), 비밀번호 10회 오류 시 10분 잠금, 봇용 숨은 칸, 스프레드시트 수식 주입 방지, 앱으로 올린 사진만 내보내기 |
| 모바일 | 휴대폰에서는 디시 모바일처럼 한 줄 목록으로 바뀜 |

## 설치하기 (약 10분)

준비물: 구글 계정 하나.

1. <https://script.google.com> 에 들어가 **새 프로젝트**를 만듭니다. 제목은 원하는 대로(예: `모두의 갤러리`).
2. `src/` 폴더의 파일을 그대로 옮깁니다.
   - 처음 있는 `Code.gs` 의 내용을 모두 지우고 [`src/Code.gs`](src/Code.gs) 내용을 붙여넣습니다.
   - 왼쪽 **파일 +** → **HTML** 로 파일 3개를 만들고 각각 내용을 붙여넣습니다.
     이름은 정확히 `Index`, `Styles`, `App` (`.html` 은 자동으로 붙습니다).
   - (권장) 왼쪽 **⚙ 프로젝트 설정** → "편집기에서 `appsscript.json` 매니페스트 파일 표시"를 켜고,
     생긴 `appsscript.json` 내용을 [`src/appsscript.json`](src/appsscript.json) 으로 바꿉니다. (한국 시간대, V8)
3. 위쪽 함수 선택 칸에서 **`setup`** 을 고르고 **실행**합니다.
   - 권한 요청이 뜨면 본인 계정을 고르고 승인합니다.
     "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (프로젝트 이름)(으)로 이동**을 누르세요. 내가 만든 스크립트라서 나오는 안내입니다.
   - 아래 **실행 로그**에 데이터 스프레드시트 주소, 사진 폴더 주소, **관리자 키**가 나옵니다.
4. 오른쪽 위 **배포 → 새 배포** → 유형 선택(⚙) **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - **배포**를 누르면 나오는 **웹 앱 URL** 이 커뮤니티 주소입니다.
5. 주소로 들어가 보세요. 첫 화면에 "이용 안내" 공지가 올라가 있으면 성공입니다.

### 코드를 고친 뒤에는

**배포 → 배포 관리 → ✏(수정) → 버전: 새 버전 → 배포** 를 해야 실제 주소에 반영됩니다. (주소는 그대로 유지)

### (선택) clasp 로 한 번에 올리기

```bash
npm install -g @google/clasp
clasp login
cd community
clasp create --type webapp --title "모두의 갤러리" --rootDir src
clasp push
```

그다음 편집기에서 `setup` 실행 → 웹 앱 배포는 위와 같습니다.

## 관리자 사용법

- 스크립트를 만든 **본인 구글 계정으로 로그인한 상태**로 접속하면 자동으로 관리자입니다. (위쪽에 `관리자 모드` 표시)
- 다른 사람에게 관리를 맡기려면 관리자 키를 알려 주세요. 화면 맨 아래 **관리자 로그인**에 키를 넣으면 6시간 동안 관리자입니다.
- 키를 바꾸려면 편집기에서 **`resetAdminKey`** 를 실행합니다. (이전 키와 로그인은 모두 무효)
- 관리자가 할 수 있는 일
  - 글을 열면 아래쪽 빨간 **관리** 막대: 공지로 올리기/내리기, 작성자 차단
  - 글·댓글 **삭제**를 비밀번호 없이 (관리자 글·댓글은 일반 사용자가 지울 수 없음)
  - **관리 페이지**: 갤러리 만들기 · 이름/설명/말머리/개념글 기준/순서 바꾸기 · 숨기기, 차단 목록과 해제, 데이터 시트/폴더 바로 가기

## 설정 바꾸기

`Code.gs` 맨 위 `CONFIG` 에서 바꿀 수 있습니다. 바꾼 뒤 새 버전으로 다시 배포하세요.

| 항목 | 기본값 | 설명 |
| --- | --- | --- |
| `SITE_NAME`, `SITE_DESC` | 모두의 갤러리 | 사이트 이름과 소개 |
| `PAGE_SIZE` | 30 | 목록 한 쪽의 글 수 |
| `DEFAULT_NICK` | ㅇㅇ | 닉네임을 비웠을 때 이름 |
| `MAX_IMAGES`, `MAX_IMAGE_MB` | 20장, 5MB | 글 하나의 사진 수, 한 장 용량 |
| `POST_COOLDOWN_SEC`, `COMMENT_COOLDOWN_SEC` | 20초, 5초 | 도배 방지 간격 |
| `BEST_HOURS` | 72 | 실시간 베스트 집계 기간 |
| `RESERVED_NICKS` | 운영자, 관리자, admin | 일반 사용자가 쓸 수 없는 닉네임 |
| `GALLERIES` | 자유·사진·유머·건의 | **처음 setup 때만** 쓰는 기본 갤러리 (이후엔 관리 페이지에서) |

## 데이터는 어디에 저장되나요?

내 드라이브에 **`모두의 갤러리 데이터`** 폴더가 생깁니다.

- `모두의 갤러리 DB` 스프레드시트: `galleries`(갤러리) · `posts`(글) · `comments`(댓글) · `images`(사진 목록) · `votes`(추천 기록) · `bans`(차단)
- `사진` 폴더: 올라온 사진 파일

참고

- 글자 칸은 `"안녕하세요"` 처럼 따옴표가 붙은 형태로 저장됩니다. 누군가 `=IMPORTXML(...)` 같은 수식이나 `1/2`(날짜로 바뀜), `007`(숫자로 바뀜)을 써도 그대로 보존하기 위해서입니다. 시트에서 직접 고칠 때는 따옴표 없이 써도 됩니다.
- 글을 지우고 싶으면 행을 지우기보다 `deleted` 칸을 `TRUE` 로 바꾸는 편이 안전합니다. (행을 지워도 동작은 합니다)
- 백업은 폴더를 통째로 복사하면 됩니다.
- 글에 붙지 않고 하루가 지난 사진(쓰다 만 글)은 매일 새벽 4시에 자동으로 휴지통에 들어갑니다.

## 알아 두면 좋은 점

- **IP 대신 식별코드**: Apps Script 웹 앱은 방문자 IP를 알 수 없습니다. 그래서 브라우저마다 무작위 값을 만들어 서버의 비밀 값으로 해시한 4자리 코드를 `ㅇㅇ(3fa9)` 처럼 보여 줍니다. 브라우저 데이터를 지우면 코드가 바뀌므로 차단도 기기(브라우저) 단위입니다.
- **사진 공개 방식**: 사진은 "링크가 있는 모든 사용자 보기"로 저장하고 구글 드라이브 썸네일 주소로 보여 줍니다. 회사·학교 계정처럼 외부 공유가 막힌 계정이면 자동으로 서버를 거쳐 보여 줍니다(조금 느림). GIF는 움직이도록 항상 서버를 거칩니다.
- **사용량 한도**: 무료 구글 계정은 동시에 처리할 수 있는 요청 수 등 [Apps Script 할당량](https://developers.google.com/apps-script/guides/services/quotas)이 있습니다. 소규모~중간 규모 커뮤니티에 알맞고, 글이 수만 개를 넘으면 목록이 느려질 수 있습니다.
- 웹 앱 맨 위에 구글이 띄우는 안내 문구(구글이 아닌 사용자가 만든 앱이라는 표시)는 구글 정책이라 없앨 수 없습니다.

## 로컬에서 미리 보기 · 테스트 (선택, Node.js 18 이상)

배포에는 `src/` 만 있으면 됩니다. `dev/` 와 `test/` 는 실제 구글 서버 없이 확인하기 위한 도구입니다.
(`dev/gas-mock.js` 가 스프레드시트·드라이브·캐시 등 Apps Script 서비스를 흉내 냅니다.)

```bash
cd community
npm test            # 서버 코드 테스트 27개
npm run dev         # http://localhost:8787 에서 미리 보기 (데이터: dev/.data/)
npm run dev:owner   # 스크립트 주인(자동 관리자)으로 접속한 것처럼 미리 보기
```

## 파일 구성

```
community/
├─ src/                 ← Apps Script 에 올리는 파일 (이것만 있으면 됨)
│  ├─ Code.gs           서버: 저장소, API, 관리자 기능, setup()
│  ├─ Index.html        페이지 틀
│  ├─ Styles.html       디자인 (CSS)
│  ├─ App.html          화면 동작 (JavaScript)
│  └─ appsscript.json   프로젝트 설정 (시간대, 웹 앱 권한)
├─ dev/                 로컬 미리 보기 서버 + Apps Script 흉내
└─ test/                서버 테스트
```
